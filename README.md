# 📚 Система управления библиотекой

Учебный проект. Вариант 1. Автор: Admin

## 📖 Описание

Система автоматизирует библиотечные операции:
- выдачу книг читателям
- возврат книг
- расчёт штрафов за просрочку и порчу
- блокировку недобросовестных читателей
- напоминания о возврате

## ⚙️ Возможности

| Функция | Описание |
|---------|----------|
| Выдача книги | Проверка читателя, доступности, лимитов |
| Возврат книги | Расчёт штрафа за просрочку и порчу |
| Продление | До 2 раз |
| Штрафы | 10 руб./день просрочки, 1000 руб. за порчу |
| Блокировка | При штрафе > 500 руб. или просрочке > 30 дней |
| Уведомления | Через threading.Timer |

## 📏 Бизнес-правила

| Категория | Лимит книг | Срок выдачи |
|-----------|-----------|-------------|
| Студент   | 5         | 14 дней     |
| Сотрудник | 10        | 30 дней     |
